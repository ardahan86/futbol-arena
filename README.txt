FUTBOL ARENA - Eski maç detayları düzeltmesi

Bu pakette yalnızca app.js güncellenmiştir. players.js, Excel futbolcu verileri ve puanlar değiştirilmemiştir.

Yükleme:
1. GitHub'da ardahan86/futbol-arena deposunu aç.
2. app.js dosyasını aç ve kalem (Edit) simgesine tıkla.
3. Mevcut içeriği bu paketteki app.js içeriğiyle değiştir.
4. Commit changes ile main dalına kaydet.
5. GitHub Pages dağıtımı bitince siteyi Ctrl+Shift+R ile yenile.

Not: Önceki sürümde oynatılmış maçların skorları korunur. Bu maçların geçmiş istatistikleri saklanmadıysa, rapor açıldığında skorla uyumlu örnek istatistikler oluşturulur. Bu, gerçek geçmiş maç olaylarının geri getirilmesi değildir. Yeni maçların istatistikleri normal simülasyonda oluşturulur.
