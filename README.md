FUTBOL ARENA — 300 OYUNCULUK GÜNCEL PAKET

Dosyalar:
- index.html: Site arayüzü
- styles.css: Tasarım
- app.js: Mevcut lig ve maç simülasyon motoru
- players.js: Yüklediğin players.json dosyasındaki 300 oyuncunun, motorun beklediği biçime uyarlanmış sürümü

Kurulum:
1. ZIP'i çıkar.
2. Bu dört dosyayı GitHub futbol-arena deposunun ana klasörüne yükle; eski dosyaların üzerine yaz.
3. Commit changes ile kaydet.
4. GitHub Pages dağıtımının tamamlanmasını bekle.
5. Siteyi ?v=20261014 parametresiyle aç veya tarayıcı önbelleğini yenile.

Not:
- Oyuncu adları, kulüpleri, mevkileri ve puanları yüklediğin players.json içeriğinden alınır.
- app.js maç/lig motoru korunmuştur.
- Önceden tarayıcıda saklanan eski kadro seçimleri, oyuncu kimlikleri değiştiyse yeni listede yeniden seçilmek zorunda kalabilir.
